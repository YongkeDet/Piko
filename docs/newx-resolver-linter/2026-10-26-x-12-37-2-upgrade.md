## 构建输入传输问题

第一次上传中文 XML 时，终端返回的大段 JSON 中间被截断，导致远程输入少于 1312 条。预览工作流 `40323164493` 在加载补丁前退出，完整错误为 `ValueError: The release string count does not match the translation`（`build_cloud.py:24`）。归因为源码传输/产物准备，不是 resolver、linter 或 APK 合同失败。

按块读取原始 UTF-8 字节并以 base64 创建 Git blob，核对 Git SHA-1 `b003083aa0af050d008f22458c43f19889729912` 与中文资源 SHA-256 `4e20d77f5a4df31ba45fc0f57f17673e07618a3bb6b452b5f9bed4ec33f88fc0` 后重新构建，完整检查通过。失败构建没有产出或发布补丁，没有为此修改 resolver 或添加无关测试。
